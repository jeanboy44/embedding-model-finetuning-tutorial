## 2. 0.95까지의 거리 — 무엇이 가능한가

A의 실패는 338문항이다. 정답 순위로 나누면 6~10위 93, 11~30위 103, 31~100위 74, 100위 밖 68이다[측정].
**6~30위를 전부 고쳐도 R@5는 0.90이다.** hard negative 계열만으로는 0.95에 닿을 수 없다. 멀리 놓친 142문항(10%p)은 질문과 조문 사이의 어휘 간극이나 라벨 문제일 가능성이 크고, 4단계 합성 질문의 몫이다 [추론].

## 3. 다음 실험 후보 순위

| 순위 | 후보 | 비용 | 근거·기대 |
|---|---|---|---|
| 1 | **A·B(·C) 가중치 평균(model soup)** — 새 후보. 학습 없이 평가만 한다 | 약 10분 | 같은 초기값에서 파인튜닝한 모델들이다(Wortsman 2022, https://arxiv.org/abs/2203.05482). "A나 B 중 하나라도 맞힘" 상한은 0.795로, seed 두 개의 상한 0.741보다 훨씬 크다[측정]. 모델 하나로 남으므로 제약 위반이 아니다 |
| 2 | **4단계 합성 질문**(어휘 간극) | 큼 | 남은 실패 중 가장 큰 덩어리(멀리 놓친 10%p)를 겨냥한다. 새로 만든 질문은 A로 채굴하면 train 과적합 편향도 없다 |
| 3 | 2라운드 채굴(A로) | 1 run | A의 train R@5가 0.92라 train 질문에서는 어려운 후보가 줄어든다(과적합 편향이 더 심해진다). 합성 질문과 묶을 때 가치가 커진다. 기대 +0.01~0.02 [추론] |
| 4 | CachedGIST(guide = 얼린 A) 또는 `hardness_mode` | 1 run | 판정을 대신해 학습 중에 가짜 negative를 거른다. GISTEmbed https://arxiv.org/abs/2402.16829. hardness: https://arxiv.org/abs/2503.04812, EmbeddingGemma https://arxiv.org/abs/2509.20354. 3단계 계획과 같은 축이다 |
| 5 | 배치 32→64 (CachedMNRL) | 시간 거의 같음 | 메모리는 일정하고 epoch당 연산도 비슷하다. RocketQA에서 in-batch 32.39 → cross-batch 33.32. 싼 부가 변형으로 쓸 만하다 |
| 6 | scale 20→50 | 0 | E5 사전학습은 τ=0.01이었다. 근거가 약해서 묶음 변형으로만 |
| 7 | A·B negative 섞기 | 1 run | 근거로 삼은 트레이드오프가 잡음 수준이라 우선순위가 낮다 |
| 8 | negative 5~7개, curriculum | 1.5배 / 1 run | 개수 효과가 불확실하다. curriculum은 Arctic에서도 사후 실험이라 근거가 약하다 |
