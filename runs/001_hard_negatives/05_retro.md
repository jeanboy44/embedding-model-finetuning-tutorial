# 001 hard negative 재채굴 — 5. 회고 (전문가 검토 반영)

## 잘된 것

- **사전 등록과 대조군 재학습.** 대조군을 같은 코드·같은 epoch로 seed 3개 다시 학습해서 seed 범위가 0.0014라는 것을 알았다. 덕분에 +0.03~0.04의 차이를 확신할 수 있다. exp_009를 대조군으로 썼다면 epoch 스케줄 차이가 섞였을 것이다.
- **방법론 검토가 누수를 막았다.** 채굴 후보의 15~19%가 dev·test 법령 문서였다. 방법론 검토가 이를 짚어 train 법령으로 제한했다. 이 제한이 없었다면 "처음 보는 법령" 수치가 부풀었을 것이다.
- **C로 효과를 분리했다.** 출처가 주효과라는 것을 확인했다. 개수 효과는 단일 seed로는 판단할 수 없었다(CI [−0.003, +0.023]).
- **질문별 qid와 top-10 기록.** 고친·망친 질문과 실패 유형 비교(compare_runs.py)를 바로 할 수 있었다.

## 아쉬운 것과 개선

### 실험 방법
1. **판정 비용 대비 효과가 없었다.** 9,009쌍(agent 30개, 대략 수백만 토큰)을 판정했지만 B는 A를 넘지 못했다.
   - 개선: 판정이 필요한지 먼저 작은 비용으로 확인한다. 예를 들어 판정 표본 수백 쌍만 써서 "제거" 대 "판정 후 유지"를 짧게 학습해 비교한 뒤 전체 판정 여부를 정한다.
   - 다만 판정 결과(95% 이상 구간의 29%가 진짜 negative가 아님)는 데이터 품질 지표로 남는다.
2. **A·C에서 학습 질문 81개가 빠졌다.** 계획에 없던 차이다.
   - 개선: 채굴 manifest를 만들 때 "negative 0개 질문 수"를 출력하고, 계획에 처리 규칙을 미리 적는다. 예: 30위 밖까지 확장하거나, 기존 negative로 대체한다.
3. **best epoch가 3, 4로 섞여 있다.** dev 간이 평가로 epoch를 고른다.
   - 간이 평가(0.751)와 공식 평가(0.761)는 partial 제외 여부 때문에 다르다.
   - 개선: 간이 평가도 partial_ids를 순위에서 빼도록 맞춘다.
4. **판정 일관성.** 샤드마다 full 비율이 1.4%~16%로 다르다. 쌍둥이 조문(대상만 다른 같은 문구)과 다른 법의 같은 규칙에 대한 처리가 agent마다 갈렸다.
   - 개선: 판정 기준에 사례 목록을 넣고, 처음 몇 샤드의 결과를 보고 기준을 확정한 뒤 나머지를 돌린다.

### 로깅
1. **agent들이 scratchpad를 공유해 보조 스크립트를 서로 덮어썼다.** 결과 파일에는 문제가 없었지만(검증 통과), 한 agent는 다른 샤드 내용으로 96줄을 판정했다가 지웠다.
   - 개선: agent마다 전용 폴더를 지정한다(2차 wave부터 적용함). 출력 검증 스크립트를 판정 직후 자동으로 돌린다.
2. **학습 로그에 실제 학습 행 수와 negative 0개 질문 수를 바로 남기지 않았다.** train_meta에는 있었다.
   - 개선: run_one.sh가 끝날 때 요약 한 줄(행 수, 시간, best epoch, 공식 R@5, Δ)을 `03_run/summary.tsv`에 덧붙인다.
3. **모니터 만료(30분)로 재설정이 잦았다.** 실험 진행에는 영향이 없었다.

### 에러 분석
1. **관계 6유형 분류가 유용했다.** B와 A가 서로 다른 혼동을 고친다는 것을 바로 보였다.
2. **아직 보지 못한 것:**
   - 실패 질문 중 정답 라벨 자체가 의심스러운 경우. 판정 agent들이 train에서 여러 건을 보고했다. 예: positive가 위임 조문만이고 하위 규정이 실제 답인 경우.
   - 질문 유형별(situation 등) 개선 폭
   - 근소한 실패(6~10위)와 크게 놓친 실패(100위 밖)의 변화
   - 개선: compare_runs.py에 질문 유형과 순위 구간 표를 넣고, 실패 표본 50개를 판정해 라벨 문제 비율을 run마다 추적한다.

## 다음 실험에 반영할 것 (검토 반영 순서)

**전제:** A의 실패 중 정답이 31위 밖인 질문이 142개다. 6~30위를 다 고쳐도 상한이 0.90이므로 **hard negative 계열만으로는 0.95에 닿지 않는다.** 크게 놓친 실패는 질문과 조문의 어휘 간극 문제라 4단계(합성 질문)가 필요하다.

| 순위 | 실험 | 비용 | 근거 |
|---|---|---|---|
| 1 | **A·B·C 가중치 평균(model soup)** | 학습 없음, 약 10분 | 둘 중 하나라도 맞히는 상한 0.795(A·B). seed끼리는 0.741. 모델은 그대로 e5-small 하나다 |
| 2 | **합성 질문 (4단계)** | 생성 + 학습 | 크게 놓친 실패를 겨냥하는 유일한 수단. 0.95를 위해 필수 |
| 3 | A로 2라운드 채굴 | 학습 1회 | 문헌 효과는 대조군에 따라 다르다(ANCE +2~3pt는 BM25 negative 대비라 과장) |
| 4 | GIST(얼린 A를 guide로) 또는 hardness_mode | 학습 1~2회 | 판정 없이 가짜 negative를 거른다 |
| 5 | 배치 64, scale 조정 | 학습 각 1회 | 작은 효과 예상 |
| — | negative 섞기·개수 늘리기 | | 이번 결과로는 근거가 약하다(후순위) |

- 학습은 최대 epoch 3으로 줄인다(A·B 모두 epoch 3이 최고).
- 4단계(합성 질문)는 0.95의 기준(처음 보는 법령 대 코퍼스 전체)을 정해야 시작할 수 있다. **강사 결정이 필요하다.**
