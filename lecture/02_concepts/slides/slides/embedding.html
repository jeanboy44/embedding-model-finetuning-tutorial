문장을 숫자 벡터로 바꾼다

의미가 가까운 문장은 벡터도 가깝다. 단어가 달라도 뜻이 같으면 가까이 놓이는 것이 좋은 임베딩이다.

“비밀번호를 까먹었어요”

→ [0.12, −0.53, 0.08, … ] 수백 개의 숫자

비밀번호를 까먹었어요

계정 복구 절차

택배가 안 와요

배송 지연 안내

벡터 공간 (2차원으로 줄여 그림)

임베딩 모델은 문장을 숫자 벡터로 바꿉니다. 보통 수백 개의 숫자입니다. 의미가 가까우면 벡터도 가깝게 놓입니다. "비밀번호를 까먹었어요"와 "계정 복구 절차"는 겹치는 단어가 없지만 가까이 놓이고, "택배가 안 와요"는 "배송 지연 안내" 근처에 놓이는 식입니다. 그림은 개념도입니다. 선택 실습: uv run python lecture/02_concepts/01_embedding_exploration.py. 직접 돌려 보면 관련 있는 두 문장이 0.909, 전혀 무관한 문장도 0.79처럼 높게 나옵니다. e5는 유사도가 전반적으로 높게 나오는 모델이라 절대값이 아니라 순위를 봐야 합니다.
