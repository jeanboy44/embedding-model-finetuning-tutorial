이번 시간의 목표

같은 모델을 세 가지 길로 건넨다

1

데스크톱 앱

모델이 사용자 PC 안에서 돈다. 인터넷 · 서버가 없어도 된다

누가: 현장 · 망분리 PC 사용자

오늘: HTML 파일 하나 ※

2

웹

모델은 서버에 두고, 사용자는 브라우저로 주소만 연다

누가: 현업 전체

오늘: React 화면 + FastAPI

3

사용자의 에이전트

사용자가 쓰는 에이전트가 우리 검색을 도구로 부른다

누가: 에이전트를 쓰는 사람

오늘: A · CLI + 스킬, B · MCP

모델과 조문 인덱스는 셋 다 같다. 다른 것은 모델이 어디서 돌고, 누가 부르느냐다.

※ HTML 파일 하나는 정식 데스크톱 앱이 아니다. 모델이 사용자 PC에서 도는 경험이 같아서 오늘은 편의상 이것으로 대신한다

오늘 마지막 시간에는 지금까지 만든 모델을 남에게 건네는 길 세 가지를 봅니다. 첫째, 데스크톱 앱. 모델이 사용자 PC 안에서 돌고, 인터넷도 서버도 필요 없습니다. 오늘은 3교시 처음에 보여 드린 HTML 파일 하나로 대신합니다. HTML 파일을 데스크톱 앱이라고 부르지는 않지만, 모델이 사용자 PC에서 돈다는 점이 같아서 편의상 이렇게 묶었습니다. 둘째, 웹. 모델은 서버에 두고 사용자는 브라우저로 주소만 엽니다. 셋째, 사용자의 에이전트에 연결. Claude Code 같은 에이전트를 이미 쓰는 사람에게는 화면 대신 도구를 건넵니다. CLI와 스킬, 또는 MCP입니다. 세 길 모두 같은 모델, 같은 조문 인덱스를 씁니다. 다른 건 모델이 어디서 도느냐, 누가 부르느냐입니다. 길마다 환경을 그림으로 보고, 언제 쓰는지, 장단점과 주의할 점을 정리하겠습니다.
