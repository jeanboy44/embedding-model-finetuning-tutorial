웹은 화면, API 서버, 모델 세 층입니다. 화면은 API만 부르고 모델은 전혀 모릅니다. 그래서 모델을 파인튜닝 모델이나 INT8로 바꿔도 화면은 그대로입니다. 배포할 때는 빌드한 화면을 API 서버가 같은 주소에서 함께 내보내니, 프로세스 하나만 띄우면 됩니다. 화면을 다시 빌드하려면 Node.js 20 이상과 pnpm이 필요하고(corepack enable), 저장소 루트에서 pnpm --dir apps/web로 설치와 빌드를 한 뒤 API 서버에 --web-dist로 넘깁니다. 04_web_app.py --run이 이 세 단계를 한 번에 합니다.
