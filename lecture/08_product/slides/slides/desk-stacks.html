이 과제에서는 다루지 않는다. 사용자가 겪는 일은 HTML 파일 하나와 같다. 받아서 열면 내 PC에서 돈다. 스택이 더해 주는 것은 설치 · 자동 업데이트 · 파일 접근 같은 앱 기능이다.

원래 데스크톱 앱을 만들려면 다른 스택을 씁니다. Electron은 웹 기술로 화면을 만들고 크롬을 통째로 넣어서 설치 파일이 보통 80에서 150MB입니다. Tauri는 운영체제에 이미 있는 웹뷰를 쓰고 핵심은 Rust라서 10MB 안팎으로 작습니다. 사내 윈도우 앱이라면 C#으로 WPF나 WinUI를 쓰고, 모델은 Microsoft.ML.OnnxRuntime으로 돌립니다. 7교시에 C# 앱 안에 넣으려면 ONNX가 필수라고 했던 게 이 경우입니다. 파이썬 코드를 그대로 PyInstaller로 묶을 수도 있지만 torch가 들어가면 수백MB에서 GB가 되니, 역시 7교시처럼 ONNX로 바꿔 넣습니다. 오늘은 이 스택들은 다루지 않습니다. 사용자 입장에서 겪는 일은 HTML 파일 하나와 같기 때문입니다. 받아서 열면 내 PC에서 모델이 돕니다. 스택이 더해 주는 건 설치 프로그램, 자동 업데이트, 내 PC 파일 읽기 같은 앱 기능입니다. 설치 크기는 2026년 기준 흔히 보이는 범위이고, 모델 크기는 따로 더해집니다.
