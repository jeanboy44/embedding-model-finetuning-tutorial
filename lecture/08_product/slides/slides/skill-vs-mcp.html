CLI + 스킬 vs MCP

CLI + 스킬MCP
건네는 것SKILL.md + CLI서버 + 등록 명령 · 설정 JSON
도는 곳사용자 PC사용자 PC (stdio) 또는 서버 (HTTP)
붙는 곳셸을 쓰는 에이전트MCP를 지원하는 앱 전부
문맥 비용필요할 때만 읽는다연결하면 도구 설명이 늘 올라간다
사람이 확인같은 명령을 쳐 본다MCP Inspector 같은 도구로 본다
우리 저장소ragkit-search skill installragkit-mcp (stdio)

둘 다 같은 Searcher를 부른다. 검색 결과는 같고, 붙이는 방식만 다르다. 실습은 CLI + 스킬 위주.

두 방법을 표로 나란히 놓으면 이렇습니다. 스킬은 SKILL.md와 CLI를 건네고, 사용자 PC에서 돌고, 셸을 쓰는 에이전트에 붙습니다. 필요할 때만 읽어서 문맥 비용이 작고, 사람이 같은 명령을 쳐서 확인할 수 있습니다. MCP는 서버와 등록 명령을 건네고, 사용자 PC에서 stdio로 돌거나 서버에서 HTTP로 돕니다. MCP를 지원하는 앱이면 어디든 붙지만, 연결하면 도구 설명이 늘 문맥에 올라갑니다. 확인할 때는 MCP Inspector 같은 별도 도구를 씁니다. 중요한 건 둘 다 같은 ragkit의 Searcher를 부른다는 점입니다. 검색 결과는 같고 붙이는 방식만 다릅니다. 셸을 쓰는 개발자 에이전트에는 스킬, 채팅 앱이나 여러 사람에게 한 번에 붙이려면 원격 MCP가 맞습니다. 오늘 실습은 스킬 쪽을 주로 합니다.
