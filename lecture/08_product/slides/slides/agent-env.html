세 번째 길은 사용자가 이미 쓰고 있는 에이전트에 붙이는 겁니다. 화면은 에이전트가 맡고, 우리는 도구와 사용 설명서만 건넵니다. 사용자 PC에는 Claude Code, Gemini CLI, Codex, Claude Desktop 같은 에이전트가 있습니다. 에이전트는 클라우드의 LLM과 대화하면서 무엇을 부를지 정하고, 우리 도구를 부릅니다. 붙이는 방법은 둘이고, 이제부터 A와 B로 나눠서 봅니다. A는 CLI와 SKILL.md입니다. 이걸 주면 에이전트가 셸로 명령을 칩니다. B는 MCP입니다. MCP 서버를 주면 에이전트가 정해진 형식으로 도구를 부릅니다. 둘 다 아래에서는 같은 모델과 조문 인덱스, 같은 Searcher를 씁니다. 우리 MCP 서버는 사용자 PC에서 stdio로 돌지만, MCP 서버를 HTTP로 원격에 두면 사용자는 설치 없이 주소만 등록하면 됩니다. 그 경우 모델은 웹처럼 서버에 있습니다. 하나 기억할 점은, 질문과 우리가 찾아 준 조문이 LLM으로 넘어간다는 겁니다.
