돌려 볼 명령

lecture/03_setup/README.md

저장소 루트에서 실행한다. 받은 산출물만 쓰므로 --run 모드가 없고, 몇 분이면 끝난다.

점검과 완성품 스크립트를 돌리고, 학습 전후 비교는 README에 모아 둔 CLI 명령을 직접 쳐 봅니다. 모두 저장소 루트에서 실행합니다. 3교시 스크립트는 받은 모델과 인덱스를 열어 보기만 해서 --run 모드가 없고, 오래 걸리지 않습니다. 점검에서 빠진 게 나오면 --fix를 붙여 다시 돌리세요.
