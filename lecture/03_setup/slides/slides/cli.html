명령 세 개로 찾고, 본다

# 법령 목록
uv run --package ragkit-search ragkit-search laws --theme youth
# 검색 상위 k개
uv run --package ragkit-search ragkit-search search "주휴수당" --law 근로기준법
# 조문 원문
uv run --package ragkit-search ragkit-search show 근로기준법_법률_제55조

질문 넷을 쳐 본다

search 뒤에 앞의 질문을 그대로. 지금은 학습 전 모델이다

사람과 프로그램 둘 다

기본은 사람이 읽는 출력, --json이면 다른 프로그램이 읽는 출력

CLI는 터미널에서 바로 씁니다. 저장소 루트에서 uv run --package ragkit-search를 앞에 붙여 실행합니다. 맨 이름 ragkit-search만 치는 건 가상환경을 켰을 때만 됩니다. laws로 법령 이름을 보고, search로 찾고, show로 원문을 봅니다. LLM이 근거를 붙여 답하는 ask 명령도 있지만 API 키가 필요해서 오늘은 쓰지 않습니다. 앞에서 본 질문 네 개를 search 뒤에 그대로 넣어 쳐 보세요. 지금은 학습 전 모델입니다. 모델을 바꿔 끼우는 건 이 시간 마지막에 합니다. CLI는 8교시에 08_product/01_search_cli.py로 직접 다룹니다.
