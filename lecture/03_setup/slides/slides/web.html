현업이 쓰는 웹 화면 “법령 노트”. 8교시에 직접 만든다. 오늘은 강사 화면으로만 본다.

먼저 완성품을 보여 드립니다. 오늘 끝에 만들 웹 화면, 법령 노트입니다. 지금은 제 화면으로만 보시고, 직접 만드는 건 8교시입니다. NotebookLM처럼 법령 묶음을 고르고 질문하면, 키가 있을 때는 인용 번호가 붙은 답이 나오고 누르면 조문 원문이 열립니다. 오늘은 API 키 없이 쓰니 답 대신 근거 조문 목록이 나옵니다. 그 목록이 바로 임베딩 검색 결과이고, 오늘 우리가 좋게 만들 부분입니다. 화면 뒤에서 도는 것은 오늘 다룰 임베딩 검색입니다. 이제 같은 검색을 여러분 터미널에서 CLI로 직접 써 봅니다.
