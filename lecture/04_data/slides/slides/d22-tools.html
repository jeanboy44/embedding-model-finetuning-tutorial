과제를 하려면 도구부터 만든다

라벨링 도구

사람이 질문을 쓰고 정답 조문을 고르는 화면

조문 검색창, 저장 DB, 작업자 배분까지 붙는다

라벨 확인 도구

남이 단 정답을 검수하고 불일치를 보는 화면

작업자마다 기준이 달라 가이드를 몇 번 고친다

실험 스크립트

학습 · 평가 · 오답 덤프를 각각 짠다

설정을 바꿀 때마다 파일을 복사해 고친다

결과 정리

로그에서 숫자를 옮겨 적은 엑셀, 손으로 그린 표

어느 숫자가 어느 설정인지 잊는다

전부 과제 기간 안에, DS가 직접 만든다. 앞 장의 도구 표를 사람이 한 줄씩 짜는 셈이다.

2022년에 이런 과제를 받으면 모델보다 도구를 먼저 만들었습니다. 질문 데이터가 없으니 사람이 질문을 쓰고 정답 조문을 고를 라벨링 화면이 필요합니다. 만들다 보면 조문 검색창, 저장할 DB, 작업자 배분까지 붙습니다. 다른 사람이 단 라벨을 검수하는 확인 도구도 필요합니다. 작업자마다 기준이 달라서 가이드를 몇 번이고 고칩니다. 실험 쪽에서는 학습, 평가, 오답 덤프 스크립트를 각각 짜고, 설정을 바꿀 때마다 파일을 복사해서 고칩니다. 결과는 로그에서 숫자를 옮겨 적은 엑셀입니다. 이걸 전부 과제 기간 안에 DS가 직접 만듭니다. 앞 장에서 본 도구 표를 사람이 한 줄씩 짜는 셈입니다.
