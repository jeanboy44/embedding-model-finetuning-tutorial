가설

우리 질문 데이터로 학습하면 처음 보는 법령에서도 오른다

확인: test(법령 16개) R@5가 학습 전 0.513보다 오르는가

학습 명령

uv run ragkit train
--config experiments/exp_002_finetuned/config.yaml

설정값
시작 모델multilingual-e5-small
학습 데이터train 8,294행
배치32
손실CachedMNRL (mini 16)
학습률 · warmup2e-5 · 0.1
epoch최대 3
hard negative질문당 1개
최대 길이512 토큰
seed42
바퀴의 첫 두 칸입니다. 가설은 한 문장으로 씁니다. "우리 질문 데이터로 학습하면 처음 보는 법령에서도 오른다." 틀릴 수 있는 문장이어야 합니다. 학습한 법령에서만 오르고 처음 보는 법령에서는 그대로일 수도 있으니까요. 확인 방법도 미리 정해 둡니다. test 법령 16개에서 R@5가 학습 전 0.513보다 오르는지 봅니다. 설정은 experiments/exp_002_finetuned/config.yaml 한 장에 다 들어 있습니다. 시작 모델은 e5-small, 학습 데이터는 train 8,294행, 배치 32, 손실은 CachedMNRL입니다. CachedMNRL은 배치 32를 16개씩 나눠 계산해서 메모리를 아끼면서도 한 질문이 오답 31개를 보는 효과는 그대로 둡니다. 학습률 2e-5에 warmup 0.1, epoch는 최대 3, hard negative는 질문당 하나, 길이는 512토큰, seed는 42로 고정합니다. 명령은 ragkit train에 이 설정 파일을 주는 한 줄입니다.
