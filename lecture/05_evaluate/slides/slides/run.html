실행

돌려 볼 명령

# 0. 준비 확인: 데이터 · 모델 · 인덱스 (빠지면 --fix)
uv run python lecture/03_setup/01_doctor.py --quick
# 1. 데이터: 코퍼스, 분할
uv run python lecture/04_data/01_corpus.py
uv run python lecture/04_data/03_split.py
# 2. 평가: 지표와 학습 없는 e5-small, 쿼리 확장(받은 캐시 17개, API 키 없이)
uv run python lecture/05_evaluate/01_metrics.py
uv run python lecture/05_evaluate/02_query_expansion.py
# 3. 기준 실험: 원리와 받은 모델의 학습 기록 / 선택: 파일럿 30 step (약 1.5분)
uv run python lecture/06_train/01_train_taste.py
uv run python lecture/06_train/01_train_taste.py --run

명령은 위에서부터 순서대로입니다. 먼저 01_doctor.py --quick으로 3교시에 받은 데이터, 모델, 인덱스가 그대로 있는지 확인합니다. 빠진 것이 있으면 --fix가 받아 줍니다. 데이터는 01_corpus.py로 코퍼스 길이 분포를, 03_split.py로 분할과 겹침을 봅니다. 평가는 01_metrics.py로 지표를 직접 계산하고 학습 없는 e5-small을 test로 재고, 02_query_expansion.py로 받은 캐시의 17개 질문에서 쿼리 확장을 비교합니다. API 키가 없어도 됩니다. 마지막으로 01_train_taste.py는 그냥 돌리면 학습 원리와 받은 002 모델의 학습 기록을 보여 줍니다. 시간이 되면 --run을 붙여 30 step짜리 파일럿을 직접 돌려 보세요. 1분 반쯤 걸리고 결과는 임시 폴더에 쓰니 받은 모델은 그대로입니다. 40분짜리 전체 학습은 수업 시간에 돌리지 않고, 제가 미리 학습한 모델을 씁니다.
