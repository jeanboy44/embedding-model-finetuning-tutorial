3 · 기준 실험 · 학습 원리 짧게

질문을 정답 가까이, 오답에서 멀리

MNRL

배치 안의 다른 질문의 정답을 모두 오답으로 쓴다. 배치 32면 질문 하나에 오답 31개 + hard negative 1개

NO_DUPLICATES: 같은 조문이 한 배치에 두 번 들어가 “정답을 오답으로” 가르치는 일을 막는다

전체 학습

가중치 1.18억 개를 모두 바꾼다. 모델 크기(118M, 384차원)는 그대로

e5 접두어(“query: ” · “passage: ”)는 데이터가 아니라 코드에서 붙인다

원리는 짧게만 봅니다. 학습은 질문 벡터를 정답 조문 가까이, 오답 조문에서 멀리 옮기는 일입니다. MNRL은 배치 안의 다른 질문들의 정답을 공짜 오답으로 씁니다. 배치가 32면 질문 하나에 오답이 31개 생기는 셈이고, 여기에 4교시에 만든 hard negative가 하나 더해집니다. 같은 조문이 한 배치에 두 번 들어가면 정답을 오답으로 가르치게 되니 NO_DUPLICATES로 막습니다. 오늘 기준 실험은 전체 학습입니다. 가중치 1.18억 개를 모두 바꾸지만, 모델의 크기와 차원은 그대로라 배포 조건도 그대로입니다. e5는 질문 앞에 "query: ", 조문 앞에 "passage: "를 붙여야 하는데, 이건 데이터에 넣지 않고 코드에서 붙입니다.
