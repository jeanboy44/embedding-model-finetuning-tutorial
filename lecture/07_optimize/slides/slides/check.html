API 시작 · 검색 속도

torch에서 바꾸면 시작 약 3.3s → ONNX INT8 0.3s · 가지치기+INT8 0.1s, 검색 약 15 → 9ms (워밍업 후 20회 중앙값, 이 Mac)

세 가지를 확인합니다. 변환한 모델이 원본과 같은 결과를 내는지, 비교표를 보고 내 상황이라면 무엇을 고를지 한 줄로 써 보기, 그리고 3번 스크립트에서 API를 torch, ONNX INT8, 가지치기 + INT8로 바꿔 띄웠을 때 시작 시간과 검색 속도입니다. 검색은 첫 요청을 워밍업으로 버리고 20회 잰 중앙값인데, 이 Mac에서는 torch로 약 3.3초 걸리던 시작이 ONNX INT8에서 0.3~0.4초, 가지치기 + INT8에서 0.1초로 줄었고, 검색은 약 15ms에서 9ms로 줄었습니다. 여러분 노트북에서는 숫자가 다를 수 있습니다.
