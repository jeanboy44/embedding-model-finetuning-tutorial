왜 어려운가

질문과 조문은 다른 말을 쓴다

질문

1년 계약하고 카페에 들어갔는데 수습 3개월 동안은 시급을 최저임금보다 덜 준대요. 이게 되는 거예요?

정답: 최저임금법 제5조 ②

1년 이상의 기간을 정하여 근로계약을 체결하고 수습 중에 있는 근로자로서 수습을 시작한 날부터 3개월 이내인 사람에 대하여는 대통령령으로 정하는 바에 따라 제1항에 따른 최저임금액과 다른 금액으로 최저임금액을 정할 수 있다.

"알바 · 시급 · 덜 준대요" ↔ "근로자 · 최저임금액과 다른 금액". 베이스 모델은 이 어휘 차이에서 약하다.

가이드의 핵심

베이스 모델이 어려워할 질문을 쓴다

  • 일상 표현으로: 원동기장치자전거 → 전동킥보드
  • 질문자를 테마에 맞춰: 알바생, 초보 운전자, 연말정산 직장인
  • 조문 번호는 쓰지 않는다: "제5조"는 정답 누설
  • 조문 하나로 답할 수 있게: 없는 금액 · 기간을 지어내지 않는다
  • 중요한 조문에만: 권리 · 의무 · 금액은 2~3개, 위원회 구성은 0개
  • 답도 함께: 나중에 RAG 답변 평가의 기준 답

3 · 분할

질문이 아니라 법령으로 나눈다

split질문법령용도

dev1,4129epoch · 설정 고르기

질문 단위로 섞으면 같은 조문의 다른 질문이 train과 test에 함께 들어가 점수가 부풀려진다. 법령 단위로 나눠야 "처음 보는 법령에서의 성능"이다.

실행

돌려 볼 명령

# 1. 코퍼스 (받은 산출물이 있으면 건너뜀)
uv run python scripts/prepare_law_data.py
# 2. 질문: Claude Code에서 "최저임금법 질문 데이터 만들어줘"
uv run python .claude/skills/law-question-gen/scripts/law_parts.py list
# 3. 나머지 질문은 Drive에서 받는다 → data/law-questions/generated/
uv run python scripts/law_questions_drive.py download
# 4. 법령 단위 분할
uv run ragkit split data/law-questions/generated
