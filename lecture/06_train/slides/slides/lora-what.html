LoRA: Low-Rank Adaptation. 12개 층 × query · key · value 3곳 × 16 × (384 + 384) = 442,368

LoRA가 무엇인지 짧게 봅니다. 전체 학습은 모델의 가중치 1억 1천7백만 개를 전부 바꿉니다. LoRA는 원래 가중치 W를 그대로 얼려 두고, 옆에 가늘고 긴 행렬 B와 납작한 행렬 A를 붙여서 이 둘만 학습합니다. 둘을 곱하면 W와 같은 모양이 되니까, W에 더해지는 변화량만 작게 배우는 셈입니다. 우리는 attention의 query, key, value 세 곳에 붙였고, 폭 r은 16, alpha 32, dropout 0.1을 썼습니다. 학습이 끝나면 B 곱하기 A를 W에 합쳐서 보통 모델과 똑같은 모양으로 저장합니다. 그래서 학습하는 파라미터는 44만 2천여 개, 전체 1억 1천7백만 개의 0.4%입니다.
