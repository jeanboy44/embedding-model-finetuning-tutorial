# 004 context_header — 0. 오답 분석

대상: `models/finetuned/002_hard_negatives` (dev R@5 0.7534, deploy 0.7546).
분석 대상: `data/splits_article/dev_a.jsonl` (622문항) 및 002/003 공통 오답 양상.

---

## 1. 실패의 핵심 양상: 다른 법령과의 주제별 혼동

002 모델의 dev_a 154개 실패 사례 분석 결과:
1. **1위 오답의 51.4%가 다른 법령 조문**:
   - 다른 법 같은 테마: 23.4% (예: 청년기본법 ↔ 조세특례제한법)
   - 다른 법 다른 테마: 14.9% (예: 근로기준법 ↔ 산업안전보건법)
   - 같은 법 다른 종류(법률 ↔ 시행령): 23.4%
2. **근소한 순위 차이 (6~30위 실패가 65%)**:
   - 정답 조문이 6~10위에 머무는 비율 37.7%, 11~30위가 27.3%로, 정답 조문의 유사도 점수가 1~5위 오답과 매우 근접함.
3. **병목 원인 분석**:
   - 현재 코퍼스는 `title\ntext`만 임베딩하고 있음.
   - 예컨대 `title`이 "제1조 (목적)"이나 "제12조 (벌칙)"인 경우, 본문 내용에 법령 고유의 맥락이나 상위 장(Chapter) 정보("제3장 청년고용촉진", "제5장 퇴직급여제도")가 결여되어 있어 다른 법률의 유사 조문과 구분할 단서가 부족함.

---

## 2. 해결 방향: 계층적 맥락 헤더 (Contextual Header)

- 코퍼스 25,967개 문서 중 85.0%(22,082개)가 상위 `chapter`(장·절) 메타데이터를 보유하고 있음.
- 조문 본문 앞에 `[{law_name} > {chapter}] {title}\n{text}` 형태의 헤더를 결합하면:
  1. 다른 법령 조문과의 어휘/의미적 혼동을 원천적으로 분리.
  2. 같은 법률 내에서도 장/절 주제가 다른 조문 간의 오인 방지.
- **1단계 핵심 검증 포인트**:
  - 모델 재학습 없이 인덱싱만 다시 수행했을 때,
  - (1) 베이스 모델(000)의 성능 변화 (헤더의 어휘적 기여도)
  - (2) 챔피언 모델(002)의 성능 변화 (파인튜닝된 표현과 헤더의 결합 효과)
  를 명확히 분리하여 측정한다.
