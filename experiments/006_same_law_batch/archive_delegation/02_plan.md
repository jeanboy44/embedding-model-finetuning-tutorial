# 006 delegation_link — 2. 실험 계획

## 1. 가설
- **가설**: 하위법령(시행령·시행규칙) 코퍼스 텍스트 선두에 정규식으로 추출한 위임 모법 조항 헤더(`[위임: <모법명> 제X조제Y항]`)를 결합하고 파인튜닝하면, 법률↔하위법령 혼동(23.4%)이 감소하여 002 대조군 평균 대비 **dev R@5(doc)가 $\Delta \ge +0.010$ (0.765+) 유의미하게 상승**한다.

## 2. 제약 확인 (`constraints.md`)
| 항목 | 이 계획에서 지키는 방법 |
|---|---|
| 모델 크기 · 구조 | `intfloat/multilingual-e5-small` 단일 모델 유지 (384차원, 12레이어, reranker/BM25 금지) |
| 데이터 분할 | `data/splits_article` 고정. train 질문/조문만 학습에 사용. **test 셋 절대 미사용** |
| 오답 분석 / 판정 분리 | 오답 분석은 dev-a(622) 기준 통계만 참조. 판정 및 합격선은 dev 전체(1,243) 및 dev-b(621) 일반화 확인 |
| 대조군 및 seed 수 | 002 공용 대조군 3-seed(`s42`, `s43`, `s44`) 평균 대비 비교. 본 실험은 2-seed(`s42`, `s43`) 확증 |
| 예산 | 본 학습 run 2개 + 파일럿 1개로 총 3개 (예산 8개 이하 준수) |

## 3. 고정한 것 (사전 등록)
| 항목 | 값 | 근거 |
|---|---|---|
| 기본 모델 | `intfloat/multilingual-e5-small` | 프로젝트 공통 베이스라인 |
| 손실 함수 | `CachedMultipleNegativesRankingLoss` (mini-batch 16) | 002, 005와 동일한 메모리 최적화 배치 손실 |
| 에포크 / lr / warmup | 3 epoch / 2e-5 / warmup 0.1 | 001, 002, 005 동일 하이퍼파라미터 |
| Hard Negative 수 | 1개 (002에서 채굴된 negative 1개 그대로 사용) | 002와 동일 조건 (데이터 변경은 코퍼스 헤더만) |
| 위임 헤더 추출 대상 | 시행령 및 시행규칙 조문 (상위 200자 내 모법 참조 패턴) | 모법(법률)은 위임 대상이 아니므로 본문 유지 |

## 5. 누수 점검 (8종 무결성 검증)
1. **문서 ID 보존**: `corpus.json` 내 35,463개 모든 문서 ID와 순서가 원본과 100% 동일한가?
2. **법률 조문 불변**: 모법(법률) 조문 텍스트가 1글자도 변경되지 않았는가?
3. **분할 격리**: 헤더 추출 과정에서 train/dev/test 분할 간 정보 누수가 없는가? (조문 자체 텍스트 내 정규식만 사용)
4. **결정성 검증**: 동일 입력에 대해 100% 동일한 해시의 코퍼스가 생성되는가?
5. **텍스트 길이 점검**: 추가된 헤더로 인해 512 토큰 truncation이 과도하게 발생하지 않는가?
6. **빈 헤더 방지**: 매칭 실패 시 불필요한 공백/오류 태그 없이 원본 텍스트가 유지되는가?
7. **모법 명칭 정확도**: `법 제O조` 패턴 시 상위 법률명이 정확히 복원되어 결합되었는가?
8. **인덱스-모델 일치**: 학습에 사용된 헤더 코퍼스와 평가 인덱스에 사용된 코퍼스가 완전히 동일한가?

## 6. 개선 판정 기준 (합격선)
- **주 지표**: dev 전체(1,243) doc R@5
- **합격선 (AND 조건)**:
  1. $\Delta = \text{Mean}(R@5_{\text{delegation}}) - \text{Mean}(R@5_{\text{002\_control}}) \ge +0.010$ (목표 0.765+)
  2. 대응 표본 McNemar 검정 $p < 0.05$
  3. Paired-t 95% 신뢰구간 하한 > 0
  4. dev-b(621)에서도 양의 개선 ($\Delta_{\text{dev-b}} > 0$)
  5. 나빠진 법령 0개 (또는 $\Delta \ge 0$ 법령 비율 $\ge 90\%$)

## 7. 예상 시간 및 비용
- 위임 코퍼스 생성: 약 5초
- 파일럿: 약 2분
- 본 학습 2-seed: 각 38분 (총 약 76분)
- dev 평가: 각 약 4분 (총 약 8분)
- 총 소요 시간: 약 90분 내외
- 비용: LLM API 호출 0원, MPS 로컬 실행

## 8. 하지 않는 것
- LLM을 통한 문맥 재생성이나 본문 요약 (비용 및 환각 방지)
- test 셋 평가 (최종 배포 전까지 격리)
- reranker나 하이브리드 검색 도입 (단일 모델 비교 원칙)
