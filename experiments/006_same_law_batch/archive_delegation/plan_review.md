# 006 delegation_link — 계획서 검토 (IR · 방법론)

검토 대상: `experiments/006_delegation_link/02_plan.md` (v1)

## 1. IR 관점 평가
- **타당성**: 높음. dense retrieval에서 하위법령(시행령/시행규칙)은 어휘적으로 모법의 내용을 구체화·절차화한 것이 많아 질문 어휘와의 lexical/semantic mismatch가 발생함. 법률-하위법령 간 위임 조항(`[위임: 전기사업법 제7조제1항]`)을 헤더로 주입하면 모법 조문과의 dense vector alignment가 직접 강화됨.
- **004/005와의 차별성**: 004/005는 "제1장 총칙" 같은 정보량이 낮은 상투적 단어로 mean pooling 벡터를 희석시켜 실패했으나, 006은 구체적 식별자("모법명 제X조제Y항")를 주입하므로 고유 식별 정보량이 충분함.
- **주의점**: 위임 헤더가 너무 길어지면(여러 조문 나열) 본문이 512 토큰 뒤로 밀려 truncation될 수 있으므로, 상위 1~2개 핵심 위임 조문만 간결하게 추출해야 함.

## 2. 방법론 및 제약 준수 평가
- **분할 격리**: 완벽함. 질문 데이터를 변형하지 않고 코퍼스 텍스트 자체에 포함된 모법 참조 표현만 정규식으로 기계적 추출하므로 dev/test 누수 원천 차단.
- **사전 등록**: 하이퍼파라미터(lr 2e-5, epoch 3, batch 32, CachedMNRL), 모델 구조(e5-small), 합격선($\Delta \ge +0.010$, McNemar $p < 0.05$, CI > 0, dev-b 동반 상승) 사전 등록 확인.
- **대조군**: 002 공용 대조군 3-seed(평균 0.7509, [0.7458, 0.7538])를 엄격히 적용.

## 3. 권고 사항
1. 정규식 추출 시 `법 제O조` 패턴은 반드시 상위 법률명을 붙여 `[위임: <모법명> 제O조]`로 정규화할 것.
2. 모법(법률) 조문에는 헤더를 붙이지 않고(법률은 위임받는 하위법령이 아님), 시행령/시행규칙 중 위임 참조가 발견된 조문(전체의 ~72%)에만 깔끔하게 결합할 것.
3. 8종 무결성 검증을 거친 후 파일럿을 실행할 것.
