# 006 same_law_batch — 2. 실험 계획 (v2, 검토 반영)

작성: 계획 에이전트(Claude), 2026-10-12. v1을 쓴 뒤 IR · 방법론 검토(`reviews/plan_ir_expert.md`, `reviews/plan_methodology_expert.md`, 둘 다 치명적 0건)를 반영해 v2로 고쳤다. 1차 두 run(ratio0.5_s42 · ratio1.0_s42)은 v2 작성 시점에 학습 중이다. **v2의 규칙은 그 결과를 누구도 보기 전에 등록한 것이다.** 계획 에이전트는 후보 run의 결과 파일을 열지 않았다. 근거 문서는 `00_error_analysis.md`(오답 분석)와 `01_research.md`(문헌)다. dev 질문별 결과는 열지 않았고 집계 숫자만 썼다.

## 가설

**002 A1 설정(hard negative 1개 · 같은 학습 데이터 8,689행 · 3 epoch · lr 2e-5 · batch 32 · CachedMNRL)에서 배치 구성만 무작위(NO_DUPLICATES)에서 "배치의 절반(16행)을 한 법령의 질문으로 채우는 같은 법 묶음 배치(ratio 0.5)"로 바꾼다. 그러면 질문 하나가 in-batch에서 보는 같은 법 후보가 질문당 3.6개에서 14.3개로 늘어 같은 법 안의 조문을 가르는 학습 신호가 커지고, dev R@5(doc)가 공용 대조군 3-seed 평균(0.7509)보다 0.02 이상 오른다.**

- 배치 전부를 한 법령으로 채우는 ratio 1.0(같은 법 후보 질문당 42.4개)은 비교 run으로 같이 돌린다. 둘 중 확인 seed로 넘길 비율은 아래 "고정한 것"의 사전 등록 규칙으로 고른다. 어느 비율도 합격선을 넘지 못하면 가설은 기각이다.
- **기대 범위 (v2):** 우리 조건(이진 라벨 MNRL, teacher 없음, batch 32)에서 효과 크기를 직접 말해 주는 근거는 없다. 문헌이 허용하는 범위는 "합격선 근처의 개선부터 하락까지"다(`01_research.md`). 001→002(hard negative 추가)는 +0.037이었고, 배치 구성만 바꾸는 이번 변화가 그보다 클 근거는 없다. 따라서 기각돼도 놀랍지 않은 가설이다.
- **왜 50%가 주 후보인가 (v2에서 근거를 약하게 고침):**
  - teacher 없는 이진 라벨 손실에서 "비슷한 것만 모은 배치"는 나빠진 근거가 있다(kNN Sampler −3.29, GPL −2.5).
  - 우리 0.5는 질문마다 무작위와 이웃을 섞는 BatchSampler(+1.09)와 다르다. 배치마다 묶인 16행은 1.0에 가까운 상태이고, 나머지 16행은 무작위 상태다. 두 상태가 섞인 것이다.
  - B3의 K=32 vs K=|B| 차이(67.58 vs 67.28)는 유의성 표시가 없다.
  - 그래서 "0.5가 문헌상 안전하다"는 약한 사전 선호일 뿐이다. 0.5 결과는 묶인 행과 안 묶인 행이 섞인 결과로 해석한다.

### 기제: 실제 배치에서 바뀌는 in-batch 후보 (v2 추가)

출처는 IR 검토의 `runs/006_same_law_batch/work/review_ir/batch_relations.out`이다. 실제 train 8,689행에 샘플러를 돌려(seed 42, epoch 0) 셌고, 학습은 하지 않았다. 질문 하나가 보는 후보는 63개다(남의 정답 31 + 배치의 negative 32). 관계 분류는 `work/error_analysis/common.py`의 `relation`이다.

| 정답과의 관계 | none (지금) | same_law 0.5 | same_law 1.0 |
|---|---|---|---|
| 같은 법 다른 종류 · 연결 없음 (법률↔시행령) | 1.76 | **7.43** | **22.60** |
| 같은 법 같은 종류 다른 조 | 1.54 | 6.35 | 18.79 |
| 같은 조의 다른 조각 | 0.18 | 0.29 | 0.53 |
| 같은 법 다른 종류 · 위임 연결 | 0.10 | 0.22 | 0.51 |
| 다른 법 · 같은 테마 | 11.36 | 10.28 | 7.51 |
| 다른 법 · 다른 테마 | 47.99 | 38.37 | 13.00 |
| 같은 법 후보 합계 (평균 / 중앙값 / 0개인 질문) | 3.59 / 3 / 12.4% | 14.29 / 9 / 8.6% | 42.44 / 50 / 1.7% |

- 오답 분석의 실패 유형(dev-a 실패 1위 오답의 61%가 같은 법 안)과 맞는 방향으로 후보가 바뀐다. 남의 정답만 센 값은 1.45 → 7.95 → 25.22다(`analysis/sampler_check.out`).
- **늘어나는 같은 법 후보의 절반 이상이 법률↔시행령(연결 없음) 쌍이다.** 0.5에서 늘어난 10.7개 중 5.7개(53%), 1.0에서 늘어난 38.9개 중 20.8개(54%)다. 이 쌍은 라벨 표본에서 1위 오답 16개 중 8개(50%)가 full · partial이었다. 가짜 negative 위험이 가장 큰 쌍이다. 같은 종류 다른 조 후보는 4.8개(0.5), 17.3개(1.0) 늘어난다.
- 따라서 이 실험은 **"같은 종류 신호 증가"와 "법률↔시행령 신호(가짜 negative 위험 포함) 증가"를 한꺼번에** 시험한다. 두 효과를 나누는 run은 이번에 두지 않는다(아래 "불합격이어도 남기는 해석", "하지 않는 것").
- 손실은 설치본 `CachedMultipleNegativesRankingLoss` 기본 `directions=("query_to_doc",)`이다. 같은 법 질문끼리는 서로 negative가 되지 않는다. 바뀌는 것은 문서 후보뿐이다.
- 같이 보는 기제 예측(판정에는 쓰지 않음): 채택 run의 dev-a 실패 중 1위 오답이 같은 법인 비율이 줄어든다. 002 s42의 이 비율은 61%(95/154)다. 실패 n ≈ 150이면 비율 표준오차가 약 ±0.04다. 그래서 대조군 s42 · s43 · s44의 dev-a 실패에서 같은 비율을 계산해 범위를 같이 적고, **후보 값이 그 범위 아래로 벗어날 때만** "기제가 움직였다"고 읽는다.

## 개선 판정 기준 (합격선)

결과를 보기 전에 정했다. constraints.md 3절 기본값을 쓰고, 0.010 등으로 낮추지 않는다. 고른 비율(후보)이 **아래를 모두** 만족해야 합격이다.

1. **Δ = 후보 seed 평균 − 대조군 3-seed 평균(0.7509) ≥ 0.02** (후보 평균 ≥ 0.7709)
2. **Δ > 대조군 seed 범위 0.0080**
3. **질문 단위 대응 검정**(`ragkit paired-test --judge doc --k 5`, **대조군 s43 vs 후보 s43**)의 **95% CI 하한 > 0**. 그리고 McNemar p를 두 비율 사이 Holm(m = 2)으로 보정한 값 < 0.05. CI 자체는 보정하지 않는다
4. 법령 평균 R@5가 대조군 법령 평균보다 표준오차(0.0123) 이상 떨어지지 않는다. 그리고 법령별 McNemar(Holm, s43끼리)로 **유의하게 나빠진 법령이 0개**다
5. **dev-b Δ(후보 seed 평균 − 대조군 dev-b 평균 0.7574) > 0**. 반대 방향이면 개선으로 보지 않는다
6. seed 2개 이상
7. (기본값보다 엄격하게 더한 조건) 확인 seed(s43) 단독 dev R@5도 대조군 평균 0.7509보다 높다. v2에서는 3번이 s43끼리 계산되므로 거의 겹치지만 남겨 둔다

- 1~6은 `decide.py` 출력(`runs/006_same_law_batch/decision.json`)으로, 7은 summary.tsv로 확인한다. 같은 seed 대응 검정(s42 vs s42, s44 vs s44)은 summary에 남기되 판정에는 쓰지 않는다.
- 표준오차 0.0123보다 작은 차이(두 비율의 s42 차이, 단일 seed의 dev-b 차이 등)는 해석하지 않는다.
- 계산량: step 수가 같아 계산량을 맞춘 별도 대조는 두지 않는다. 학습 시간이 대조군 평균의 1.2배를 넘으면 한계로 적는다.
- **(v2) 4번 앞부분이 걸릴 때**: 대조군 법령 평균은 seed만 바꿔도 0.7829 · 0.7842 · 0.7687로 범위가 0.0155다(SE 0.0123보다 큼). 불합격 사유가 4번 앞부분 하나뿐이면 이 범위를 함께 보고한다. 판정 기준 자체는 바꾸지 않는다.
- **(v2) 4번 뒷부분의 검출력**: 법령당 dev 질문이 2~147개(중앙값 14)라 Holm(54개)으로는 거의 걸리지 않는다. 그래서 보조로 법령별 Δ 부호 개수(나빠진 법령 수 / 54)를 결과에 적는다. 판정에는 쓰지 않는다.
- **(v2) dev-b가 독립이라는 범위**: 비율 선택에서는 dev-b를 뺐다. 하지만 epoch 선택은 학습 중 dev 전체(dev-b 포함)로 한다. 대조군도 같은 방식이라 양쪽이 비슷하게 치우치지만, 5번은 "dev-b가 완전히 쓰지 않은 데이터"라는 뜻이 아니다. "오답 분석과 비율 선택 밖의 질문"이라는 뜻으로만 본다. 이것은 한계로 적는다.

### 법률↔시행령 고침 판정 (IR 중요 2, 사전 등록)

doc 판정만 하므로, 대조군 1위가 사실상 답이던 법률↔시행령 질문이 "고침"으로 바뀌면 사용자가 보는 품질은 거의 그대로인데 R@5만 오를 수 있다.

- **조건**: 고른 비율의 seed마다 고침 중 법률↔시행령 짝 비율을 구한다(위 보조 지표, dev 전체). 그 seed 평균이 **대조군끼리 비교에서 센 같은 비율의 최대보다 크면** 아래 판정을 한다. 합격 · 불합격과 상관없이 한다.
- **판정**
  - 표본: 해당 run들의 dev-a 고침 질문 중 1위 오답(대조군 쪽)이 법률↔시행령 짝인 것을 최대 40개 뽑는다. 40개를 넘으면 seed 42로 무작위로 뽑는다.
  - 판정 방법: Claude 서브에이전트가 "대조군의 1위 문서가 사실 이 질문의 답이었나"를 full / partial / no로 판정한다. 기준은 오답 분석의 라벨 표본 판정과 같다.
  - 기록: 작업 폴더 `runs/006_same_law_batch/work/judge_law_decree/`, 출력 `runs/006_same_law_batch/analysis/law_decree_judge.out`.
- **보고 (판정에는 쓰지 않음)**
  - full · partial 비율을 결과 문서에 한계로 적는다.
  - **법률↔시행령 짝 고침 · 망침을 "변화 없음"으로 본 Δ**를 같은 seed 짝마다 참고로 보고한다. 계산은 (고침 − 망침 − 법률↔시행령 고침 + 법률↔시행령 망침) / 1243이고, dev 전체 · dev-a 각각 낸다.
- 조건에 걸리지 않으면 판정하지 않고, 그 사실(비율과 기준값)만 적는다.

## 하지 않는 것

- 가짜 negative 대책은 같은 run에 넣지 않는다.
  - GIST 손실: guide가 같은 e5-small일 때의 근거가 없고, 손실 · temperature · 추가 항이 함께 바뀐다.
  - 정규식 위임 짝 가림: 1.0에서 위임 연결은 질문당 0.51개, 연결 없음은 22.6개라 위험의 일부만 막는다.
  - 같은 조 조각(parent_id) 가림.
  - 이들은 위 "다음 바퀴에서 효과를 나누는 run 후보"로 넘긴다.
- 같은 종류 / 법률↔시행령을 나누는 run을 이번에 두지 않는다. 1차 run 구성은 이미 학습 중이고, 나누는 것은 다음 바퀴 후보로 둔다.
- 법령 고르는 지수(α = 0.5)를 바꾸지 않는다. 법령별 노출 빈도가 바뀌는 두 번째 변수다.
- lr · scale · epoch 탐색을 하지 않는다. 배치가 어려워지면 최적 lr · scale이 달라질 수 있지만, 대조군에도 같은 탐색을 줘야 해 예산을 넘는다. 한계로 적고, 결과를 "고정 하이퍼파라미터에서"라는 조건을 붙여 해석한다.
- negative 0개 질문 437개를 채우지 않는다(학습 행 수가 바뀜).
- 비율 0.25 · 0.75 같은 추가 수준이나 고르지 않은 비율의 추가 seed를 두지 않는다.
- 대조군을 다시 학습하지 않는다(공용 대조군 재사용 조건 충족).
- test를 쓰지 않는다. 합격선을 0.02 아래로 내리지 않는다.
- 계획 에이전트는 학습 · 평가를 실행하지 않고, 후보 run 결과 파일을 열지 않는다. 커밋하지 않는다.
