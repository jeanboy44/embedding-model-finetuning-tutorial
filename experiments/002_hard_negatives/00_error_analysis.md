## 읽은 것

1. **오답의 55%는 다른 법령 문서가 1위다.** 그중 24%p는 테마까지 다르다. 예를 들어 노동 질문에 교통이나 세금 조문이 올라온다. 지금 학습 데이터의 hard negative는 100% 같은 법에서만 뽑아서 이 혼동을 학습할 기회가 없다.
2. **기존 hard negative는 거의 쓸모가 없다.**
   - 실패 질문의 1위가 기존 hard negative인 경우는 4.7%뿐이다.
   - train에서 기존 hard negative의 현재 순위는 50위 밖이 40%, 6~30위가 33%, 1~5위가 18%다. 대부분 이미 쉬운 negative다.
3. **같은 법 안의 혼동도 39%다.** 같은 종류의 다른 조(21%)와, 위임 연결이 없는 법률↔시행령(18%)이다. 위임 연결이 있는 쌍은 4%로 작다. 0단계 판정이 위임 연결 쌍에 집중했던 것과 달리, 실제 혼동 대부분은 위임 관계가 아닌 같은 법의 다른 조문이다.
4. **정답이 30위 안에 있는 실패가 55%다.** 상위권 근처에서 가까운 경쟁 문서를 밀어내는 학습(hard negative)이 직접 겨냥할 수 있는 범위다. 100위 밖(23%)은 negative보다는 질문과 조문 사이의 어휘 간극 문제로 보인다(4단계 합성 질문의 몫).

## hard negative 채굴 규모 (train)

- exp_009로 train 질문마다 상위 30개 후보(정답 제외)를 보면, **정답 점수의 95% 이상인 후보가 22,622개**다. 문항당 2.7개이고, 해당 질문은 4,567개(55%)다. 이 후보들은 실제로 정답일 수 있는 가짜 negative 후보라 판정이 필요하다.
- 판정 대상의 관계: 다른 법(같은 테마) 28%, 같은 법 같은 종류 23%, 같은 법 다른 종류(연결 없음) 20%, 다른 법(다른 테마) 15%, 위임 연결 9%, 같은 조 조각 6%
- 0단계처럼 단어 겹침 필터를 쓰면 판정량을 줄일 수 있다. dev에서는 30%만 남았고, 버린 쌍 중 정답은 0/100건이었다.

## 다음 단계(리서치)에서 확인할 것

- 모델이 채굴한 상위 후보 중 가짜 negative 비율이 보통 얼마인지, 우리처럼 cross-encoder 없이 LLM 판정으로 거르는 방법의 근거
- 다른 법령·다른 테마 negative와 같은 법 negative의 비율, negative 개수
- 정답 점수의 95% 기준(relative margin)이 우리 데이터에 맞는지. 판정량 22k를 줄일 근거
