# 002 hard_negatives — 4. 결과

## 결론

**001 모델로 직접 재채굴한 hard negative(정답 점수 95% 미만 상위 문서 1개)로 교체 학습한 결과, 채택 후보 A1은 dev R@5 0.7534(2-seed 평균)를 기록하여 공용 대조군 평균(0.7144) 대비 +0.0390(+3.90%p) 유의하게 상승했다.**
사전 등록한 합격선 6개 기준(Δ ≥ 0.02, seed 범위 초과, 대응 검정 CI 하한 > 0, 나빠진 법령 0개, dev-b 동반 상승, 2-seed 확인)을 모두 통과하여 **A1을 채택한다.**
탐색 run인 A3(채굴 negative 3개)은 dev R@5 0.7611(Δ +0.0467)로 추가 상승 폭을 보였으나 계산량이 1.7배라 이번 바퀴에서는 가설대로 A1을 채택하고 A3은 차기 가설의 근거로 남긴다.
채택 모델을 배포 형태(어휘 가지치기 + 동적 INT8 양자화, 29.7MB)로 변환한 뒤 측정한 dev R@5도 **0.7546**으로 원본 성능을 온전히 유지했다.

## 해석

1. **효과의 원천: 베이스 파인튜닝 모델이 실제 헷갈린 negative 제공**
   - 기존 LLM negative는 같은 법 안에서만 뽑혀 40% 이상이 이미 50위 밖으로 쉬운 오답이었다.
   - 001 모델로 캔 negative는 1위 오답의 주요 원인이었던 다른 법 관련 조문(34.2%)과 같은 법 다른 조(21.8%)를 직접 학습 신호로 제공했다.
2. **고친 질문과 새로 틀린 질문 (A1_s42 대 대조군 s42)**
   - **고친 질문: 76개** (대조군이 5위 밖으로 틀렸으나 A1이 top-5 내로 진입). 주로 다른 법 같은 테마 및 같은 법 다른 종류에서 발생하던 오답 교정.
   - **새로 틀린 질문: 30개** (순개선 +46개). 새로 틀린 질문들도 정답이 6~10위권으로 근소하게 밀린 사례가 대부분.
3. **탐색 run A3(negative 3개) 비교**
   - A3_s42는 dev R@5 0.7611(Δ +0.0467, CI [+0.0282, +0.0611], 고친 질문 84 / 새로 틀린 질문 29)로 A1보다 +0.0077 높은 성능을 기록했다.
   - 다만 학습 시간이 70분으로 A1(38분) 대비 1.8배 길다. 계산량을 통제한 사전 등록 계획에 따라 1개 출처의 순수 효과인 A1을 채택한다.
