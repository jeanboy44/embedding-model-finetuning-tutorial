# 한국 법령 검색 (ragkit-search CLI)

질문에 답하기 전에 **반드시 CLI로 조문을 찾아 읽고**, 찾은 조문만 근거로 답한다. 기억에 기대어 조문 번호나 내용을 지어내지 않는다.

## 명령

아래 명령 앞부분을 그대로 쓴다 (이 스킬을 설치할 때 정해진 실행 방법이다).

```bash
{command} search "<검색어>" -k 5 --json{options}
{command} search "<검색어>" --law "<정확한 법령 이름>" --json{options}
{command} show <조문 id> --article{options}
{command} laws --json{options}
```

- `search`: 가까운 조문 k개 (JSON). `--law`는 여러 번 줄 수 있다
- `show --article`: 같은 조의 항·호 전체 원문
- `laws --json`: `--law`에 쓸 정확한 법령 이름 목록

`search --json`은 목록을 돌려준다. 항목마다 `id`(조문 id, 예: `근로기준법_법률_제55조`), `score`(0~1, 클수록 가깝다), `text`(본문), `title`, `law_name`, `law_type`(법률·시행령·시행규칙)이 있다.

## 순서

1. **검색어 만들기**: 사용자의 말을 그대로 한 번 검색하고, 필요하면 법률 용어로 바꾼 검색어로 한 번 더 검색한다 (예: "알바 주휴수당" → "주휴일 유급휴일 1주 개근"). 검색은 질문당 2~3번이면 충분하다.
2. **법령 좁히기**: 어느 법인지 분명하면 `--law`로 좁힌다. 이름이 틀리면 오류 메시지가 비슷한 이름을 알려 준다. 모르면 `laws --json`으로 확인한다.
3. **원문 읽기**: 답에 쓸 조문은 `show <id> --article`로 항·호 전체를 읽는다. 검색 결과의 `text`는 조각일 수 있다.
4. **답하기**: 결론 → 근거 → 예외·조건 순서로 짧게 쓴다. 근거 문장마다 조문 id를 `[근로기준법_법률_제55조]`처럼 붙인다. 찾은 조문으로 답할 수 없으면 그렇게 말하고, 추측으로 채우지 않는다.

## 주의

- 이 인덱스에 든 법령(약 54개, 법률·시행령·시행규칙)만 찾을 수 있다. 판례·행정해석·최신 개정은 없다. 답 끝에 "법률 자문이 아니며 최신 법령은 국가법령정보센터에서 확인"을 한 줄 덧붙인다.
- 같은 법의 법률과 시행령을 헷갈리기 쉽다. 금액·비율·절차의 세부는 시행령에 있는 경우가 많으니 `law_type`을 확인한다.
- 명령이 종료 코드 1로 끝나면 stderr의 한 줄 안내(인덱스 없음, 모르는 법령 이름 등)를 읽고 고친 뒤 다시 실행한다.
- `ask` 명령은 쓰지 않는다 (별도 LLM 키가 필요하고, 답은 직접 쓴다).
