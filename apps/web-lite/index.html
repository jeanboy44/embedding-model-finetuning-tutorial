검색 API 서버가 이 화면을 함께 줍니다. 질문은 서버에서 임베딩하고, 조문 벡터와 비교해 가까운 조문을 돌려줍니다.

서버에 연결하는 중…

이 화면은 어떻게 동작하나요?

이 HTML 파일에는 모델도 조문도 들어 있지 않습니다. 검색 API 서버(ragkit-api)가 시작할 때 임베딩 모델과 조문 인덱스를 한 번 열어 두고, 화면은 같은 주소의 /api/search에 질문을 보내 결과만 받아 그립니다. 3교시의 오프라인 파일과 같은 디자인이지만, 무거운 것은 모두 서버 쪽에 있습니다.

순위는 조문 조각(항 · 호) 단위입니다. "같은 조 전체"를 누르면 /api/articles/…로 그 조의 조각을 모두 가져옵니다.
