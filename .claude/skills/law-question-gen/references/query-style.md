# 검색 쿼리 형식 분석 (KoAIO)

`keyword`·`question` 유형의 **형식**(길이, 어미, 꼬리어)을 실제 검색어에 가깝게 맞추려고 KoAIO를 분석했다. **내용은 쓰지 않는다.** KoAIO는 대부분 영어 검색어를 번역한 것이라 주제(미국 보험, 윈도우, 레시피)가 우리 코퍼스와 맞지 않는다. 형식만 가져온다.

- 출처: [jclee2004/KoAIO](https://github.com/jclee2004/KoAIO) (CC BY-NC 4.0). 원본 CSV는 저장소에 넣지 않는다.
- 구성: 중복 제거 7,288개 = ORCAS(빙 실제 검색어 번역) 3,265 + AIO(AI 요약 벤치마크 번역) 4,022 + 지식iN 1. README에는 지식iN 4,351개라고 되어 있지만 CSV에는 들어 있지 않다.
- 데이터셋에 들어 있는 `문법적 형태` 라벨, 어절 수, 마지막 어절을 셌다.

명사구 계열(명사구, 조사 결합, 관형절, 명사형)이 약 70%다. 사람들은 검색창에 문장보다 **명사 묶음**을 훨씬 많이 친다.

## 길이

- 명사구: 2어절 37%, 3어절 33%, 1어절 10%, 4어절 13%. **2~3어절이 70%** 다.
- 의문문: 3~6어절이 대부분이고, 7어절 이상은 주로 AIO의 긴 번역 문장이다.
- 1어절 쿼리("면허", "근로자")는 너무 모호해서 정답 조문 하나를 정할 수 없다. 우리 데이터에서는 쓰지 않는다.

## 자주 나오는 꼬리어 (마지막 어절)

방법(205), 비교(56), 의미(50), 정의(48), 종류(43), 법(42), 목록(33), 증상(31), 원인(28), 계산기(24), 예시(23), 가격(20), 차이(18), 부작용(17), 검사(15), 정보(15), 크기(14).

주제어 뒤에 "무엇이 궁금한지"를 한 단어로 붙이는 구조다. 법령 쪽으로 옮기면 **기준, 조건, 방법, 계산, 차이, 뜻, 벌금, 기간, 서류, 대상, 신고**가 된다.

## 의문문 어미

할까?(400), 무엇인가(217+97+51), 하는가?(125), 있나요(75+44), 할까요?(67), 누구인가(48), 않나요?(20), 얼마인가(17), 언제인가(14). 물음표가 없는 경우도 많다("말벌이 쏘나요", "내 서버 IP는 무엇인가").

## 가져오지 않는 것

- **"~해야 할까?" 토론형**(약 470개): AIO의 의견 질문("사형제를 폐지해야 할까?")이다. 조문이 답할 수 있는 질문이 아니다.
- **"무엇인가 / 하는가 / 누구인가" 번역체**: 한국 사람은 실제로 "~뜻", "~란", "~뭐예요"라고 친다. 형식(짧은 정의 질문)만 가져오고 어미는 구어로 바꾼다.
- 명령·요청문("~을 설명하라", "~ 보여줘"): 챗봇 지시문이지 검색어가 아니다.
