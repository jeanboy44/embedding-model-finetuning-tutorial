# 002: 임베딩 전략 - 직접 방식 vs 쿼리 확장

## 배경

검색 품질을 개선하기 위해 두 가지 접근 방식을 비교했습니다:
1. 도메인 특화 데이터로 임베딩 파인튜닝
2. 임베딩 전에 LLM으로 쿼리 확장

## 결정

교육 목적으로 두 가지 접근 방식 모두 구현하기로 결정했습니다.

## 이유

1. **파인튜닝**: 모델이 도메인 데이터에 어떻게 적응하는지 보여줌
2. **쿼리 확장**: 학습 없이 대안적 기법을 시연
3. **교육적 가치**: 학생들이 다양한 해결책을 접할 수 있음
4. **실무 적용**: 둘 다 실제 업계에서 사용되는 기법

## 결과

- 실험의 복잡도 증가
- 학생들이 여러 해결책을 경험
- 접근 방식 선택의 중요성 강조
